# Sishir Electrical & Interior

A modern and responsive business website developed for **Sishir Electrical & Interior** to showcase professional electrical and interior solutions with a clean and premium user experience.

🌐 Live Website: https://sishir-electrical.com

---

## ✨ Overview

This project is designed to represent the brand digitally with a modern interface, smooth responsiveness, and service-focused presentation. The website highlights the company's expertise, project visuals, and customer engagement sections.

---

## 🚀 Features

- Responsive modern UI
- Service showcase sections
- Interactive and smooth design
- Optimized for desktop and mobile
- Social media integration
- Fast and lightweight performance

---

## 🛠️ Built With

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

---

## 📌 Purpose

The website is created to provide an online presence for the business and help customers explore services, projects, and contact information easily.
